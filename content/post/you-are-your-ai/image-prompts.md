# 文章配图生成 Prompt

生成后将图片保存到本目录，格式为 `.webp` 或 `.png`（后续会统一转为 `.webp`），文件名与文章中引用一致。

## 视觉方案

- Primary skill: `guige-infographic`
- Primary style/layout/aspect: `guige-journal`，编辑感知识海报，9:16 竖版，暖白纸张、深蓝灰文字、青绿色与琥珀色点缀
- Why: 文章是有明确立场的 AI 工程反思，需要兼具可分享的观点张力与清晰的知识解释，避免默认的赛博终端视觉。
- Per-image overrides: `ai-support-question-map.webp` 使用 `guige-svg / flowchart / guige-light / 16:9`，以保证分支图的文字清晰可读。

## 2. watching-models-vs-building.webp — 围观与实践

Skill/style: `guige-infographic / comparison-board / 9:16`
Role: comparison
Intent: 对比“围观模型热闹”和“走进真实用户现场”的两种学习方式。

9:16 中文信息图，清晰上下或左右对照构图。左侧标题“围观”，几位开发者围着浮动的模型参数、benchmark 柱状图、工具榜单和新闻标题讨论，画面略显拥挤；右侧标题“实践”，一位开发者和真实用户坐在一起，桌上是客服工单、错误样本、简单测试清单和复盘笔记。中央用一条小箭头连接，文字为“从信息到经验”。暖白纸张、深蓝灰线条、青绿色代表实践、琥珀色代表警示；杂志编辑插画风，中文文字必须简洁、清晰、无乱码。

## 3. ai-support-question-map.webp — AI 客服需求显影图

Skill/style: `guige-svg / flowchart / guige-light / 16:9`
Role: architecture
Intent: 说明一句模糊的“提高客服效率”会分叉为真正决定系统设计的问题。

生成可编辑的 16:9 SVG 流程图，浅色背景，简体中文字体清晰。中心卡片：**“做一个 AI 客服，提高客服效率”**。向右分为五个并列问题卡片：**“谁的效率？”**、**“用户真正需要什么？”**、**“答错的代价？”**、**“何时转人工？”**、**“如何证明有用？”**。每张问题卡片再各以细线指向一项工程决策：用户旅程、知识与上下文、风险与权限、人工接管规则、评估集与错误分析。底部横向结论条：**“需求理解会进入系统设计”**。布局克制、圆角卡片、深蓝灰线条、青绿强调色、琥珀警示色；不要渐变、不要 3D、不要英文、不要复杂装饰。

## 4. ai-engineering-skills-loop.webp — 四项能力闭环

Skill/style: `guige-infographic / dense-modules / 9:16`
Role: section explainer
Intent: 让读者直观看到 Andrew 的四项能力围绕同一需求形成闭环，而非一张待学清单。

9:16 中文信息图，中心是一张卡片“AI 客服：提升效率？”，外围是四个环形模块，箭头形成闭环。模块文字必须准确：
1. **构建与部署 AI 应用**：评估、错误分析、治理
2. **软件工程基础**：成本、可靠性、安全、隐私
3. **使用 Coding Agent**：上下文、规格、验证闭环
4. **塑造构建方向**：用户、业务、取舍、责任

模块间的箭头旁只放极短文字：“理解 → 构建 → 验证 → 迭代”。风格为暖白纸张上的高密度编辑信息图，深蓝灰文字，青绿色主强调，琥珀色标出风险；清晰、克制、适合手机阅读，所有简体中文必须准确。

## 5. you-are-your-ai.webp — 人与 AI 的投射关系

Skill/style: `guige-infographic / guige-journal / 9:16`
Role: metaphor
Intent: 视觉化文章总命题：AI 会放大人的洞察，也会放大人的盲区。

9:16 竖版中文概念信息图。上半部是一位开发者的侧面剪影，剪影内部是四个可读标签：**“用户理解”**、**“工程判断”**、**“实践经验”**、**“责任边界”**；下半部是一个温和的 AI 系统轮廓，二者之间由流动的线条连接，最终汇成一块产品体验界面。在线条阴影中保留两个小标签：**“未问出的需求”**、**“未验证的假设”**，表达盲区也会被放大。底部仅放准确大字：**“你是什么，你的 AI 就是什么”**。暖白、深蓝灰、青绿色与少量琥珀色，成熟杂志插画，留白充分，避免机器人头像、霓虹赛博和复杂电路。

## 使用说明

1. 将上述 prompt 分别输入 AI 图片生成工具。
2. 默认使用 9:16 竖图；`ai-support-question-map.webp` 是 16:9 SVG 图。
3. 生成后保存到本目录；PNG 或 WebP 均可，后续会统一转为 WebP。
4. 文章中已按对应文件名引用图片。
