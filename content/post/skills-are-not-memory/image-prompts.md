# 文章配图生成 Prompt

生成后将图片保存到本目录，格式为 `.webp` 或 `.png`（后续会统一转为 `.webp`），文件名与文章中引用一致。

## 视觉方案

- 角色基准：`~/Downloads/guige.png` 中的鬼哥——深棕乱发、橙色“鬼哥”头带、蓝色卫衣、暖色 Q 版动漫人物。
- Primary style/layout/aspect: 暖白纸张、黑色手绘线条、青绿色与琥珀色强调，统一 9:16 竖版。
- Why: 文章既有论文数据，也有个人开发者的菜单比喻；让鬼哥在每一张图里承担“困惑、拆解、验证”的叙事角色，数据和观点才不会变成冷冰冰的基准测试截图。

## 1. cover.webp — 封面：Skill 选择困难

Style: 暖色小饭馆叙事插画 / 9:16
Role: cover
Intent: 用“菜单太长”隐喻 Skill 库太大后，Agent 从能力增强走向选择过载。

鬼哥坐在小饭馆菜单前，菜单以不同“Skill 选项”隐喻选择过载；用标题点出问题。画面保留真实菜单的烟火气与工程任务的克制感。

---

## 2. skills-as-procedural-anchors.webp — 从轨迹到程序锚点

Style: 流程对比信息图 / 9:16
Role: section explainer
Intent: 对比原始历史轨迹、Workflow Memory 与蒸馏 Skill，说明 Skill 的价值在稳定行动而非塞知识。

9:16 中文信息图。顶部是一团杂乱的终端日志、失败分支与重复命令，标题“历史轨迹”；中部两条分叉路径：左边“Workflow Memory”保留长流程、灰色噪声和超时沙漏，右边“Skill”被压缩为四张简洁卡片“步骤顺序 / 检查点 / 风险提示 / 验证方式”。右下角放一个醒目圆形数据标签：**“65.7%：程序锚点”**；旁边小标签：**“4.5%：知识注入”**。所有文字必须准确简体中文，暖纸张、黑线条、青绿色正确路径、琥珀色提示风险。

---

## 3. skill-contract.webp — Skill 的程序合同

Style: 鬼哥手绘教学卡 / 9:16
Role: checklist
Intent: 把文章最可执行的框架压成一张可保存的 Skill 模板卡。

9:16 暖奶油纸手绘知识卡，标题：**“一份可靠的 Skill，至少写清四件事”**。中央是一份简洁的 `SKILL.md` 文件卡，分为四个颜色模块，文字必须准确：
1. **适用前提**：输入、环境、权限
2. **执行路径**：关键步骤的顺序
3. **验证标准**：运行什么、何时通过
4. **退出与升级**：不适用时停止、转人工、换方案

每个模块配简洁图标：地图、流程箭头、检查清单、出口/升级箭头。鬼哥在画面下方指向主文档。页脚一句：**“没有退出条件的 Skill，会把经验固化成偏见。”**。中文清晰、无赛博风。

## 4. retrieval-is-not-success.webp — 检索命中不是成功

Style: 鬼哥数据新闻图 / 9:16
Role: comparison
Intent: 用精确可读的图表解释论文中“实际命中下降、下游成功未同步崩掉”的反直觉结果。

暖色 9:16 数据图：候选 Skill 数从 **5** 到 **100**；青绿色折线“实际使用精确率：29.6% → 3.3%”显著下降，琥珀色折线“下游任务成功率：36.4% → 39.3%”近乎平稳。鬼哥拿放大镜审视图表；结论卡为 **“精确调用正确 Skill ≠ 任务成功”**。

---

## 使用说明

1. 将上述 prompt 分别输入 AI 图片生成工具。
2. 四张图均为 9:16 竖图，并使用同一鬼哥人物形象。
3. 生成后保存到本目录；PNG 或 WebP 均可，后续会统一转为 WebP。
4. 文章中已按对应文件名引用图片。
